# Hi, I'm Eduardo

AI Engineer based in Tenerife, Spain. I build production RAG systems,
LLM pipelines, and document AI for clients in the US and Spain.

Current work: retrieval quality, chunking strategies for regulated
document domains, and the unglamorous reliability layer of LLM
applications — evals, hallucination detection, observability.

**Stack I use daily:** Python, FastAPI, Qdrant, Ollama, Docker, AWS,
PostgreSQL, n8n.

**What I'm working on publicly:** most of my production work is under
client NDAs, so I build parallel projects on public data to share the
patterns.

- [fastapi-rag-lab](https://github.com/egtimer/fastapi-rag-lab): RAG over
  the FastAPI docs, with retrieval benchmarks and an LLM faithfulness judge
  calibrated against two human labellers.
- [agentic-sql-assistant](https://github.com/egtimer/agentic-sql-assistant):
  a LangGraph text-to-SQL agent with an MCP server, evaluated on BIRD and a
